## 设备信息

- 机型：New 3DS XL（日版）
- 区域：日版（JPN）
- 区码：日版机优先对应日版卡带；美版/欧版卡带无法直接运行，除非自行改机解除区域限制

日版机的实际影响：日本游戏最方便、也最容易买到；但日版卡带绝大多数只有日文，玩之前要先确认语言。

## 先划重点

- 3DS 有区域锁：日版机最方便玩日版卡带，美版机对应美版。改机（CFW）可以解除区域限制，但属于自行研究的操作。
- Nintendo eShop 已于 2023 年 3 月关闭，官方数字版基本无法购买，现在主要靠实体卡带。
- 新 3DS 比旧 3DS 多出 C 摇杆、ZL/ZR 按键、面部追踪 3D 和更强 CPU；部分游戏只有新 3DS 能跑。
- 关于安装包：eShop 已关闭，我不会整理盗版下载指引；可以把卡带收藏、版本和状态整理成游戏库。

## 按类型补充

### 动作与平台

- 新超级马力欧兄弟 2：2D 马力欧，金币收集为主
- 路易吉洋馆 2：探索鬼屋，吸尘器玩法的解谜冒险
- 大金刚国度 回归 3D：硬核平台跳跃，难度偏高
- 星之卡比 三重豪华：轻松平台动作，关卡有趣
- 光神话 帕尔提娜之镜（Kid Icarus: Uprising）：口碑极高的动作射击，但操作比较挑人
- Shovel Knight / SteamWorld Dig / SteamWorld Heist：eShop 时代的优质独立游戏

### RPG 与冒险

- 勇者斗恶龙 VII / VIII 3D 版：经典 JRPG 的强化移植
- 真女神转生 IV：硬核黑暗向 JRPG，迷宫探索有挑战性
- 光辉物语 完美编年史：时间旅行叙事，剧情向 JRPG
- 符文工房 4：种田 + ARPG + 恋爱，非常耐玩
- 幻想生活（Fantasy Life）：轻松的职业生活 RPG
- 世界树迷宫系列 / Persona Q：迷宫探索 + 队伍养成，适合核心玩家
- 马里奥与路易吉 RPG 系列：回合制但带动作指令，轻松有趣

### 文字冒险与解谜

- 逆转裁判 5 / 6：法庭推理，剧情和演出都很强
- 雷顿教授 VS 逆转裁判：两大系列联动，质量很高
- 极限脱出 善人死亡：密室逃脱 + 剧情分支
- 绘图方块 3D 第 2 回 / Picross 3D Round 2：最耐玩的益智游戏之一
- Pushmo / BoxBoy 系列：小巧精致的解谜，适合碎片时间

### 策略与战棋

- 火焰纹章 if / 回声：觉醒之后的两部火纹，口碑和玩法各有侧重
- Code Name: S.T.E.A.M.：蒸汽朋克题材的回合制策略，比较挑人
- Ghost Recon: Shadow Wars：意外不错的掌机战棋

### 音乐、休闲与聚会

- 节奏天国 The Best+（Rhythm Heaven Megamix）：关卡式音乐游戏，创意十足
- Theatrhythm Final Fantasy: Curtain Call：FF 音乐的节奏游戏
- 朋友聚会（Tomodachi Life）/ 迷托邦（Miitopia）：轻松搞笑的模拟养成
- 绘图方块系列：益智解谜

## 新 3DS 专属

- Xenoblade Chronicles 3D：异度神剑 3D，只有新 3DS 能运行，值得优先考虑
- Minecraft: New Nintendo 3DS Edition：我的世界新 3DS 版，只有新 3DS 能运行
- SNES 虚拟主机游戏：新 3DS 独占的 SFC 模拟游戏（eShop 已关闭，只影响此前购买）
- 部分游戏对新 3DS 有优化：怪物猎人 4G/XX 用 C 摇杆调整视角更顺手，宝可梦等游戏的读取速度也有改善

## 语言提醒

- 官方中文游戏极少：宝可梦 太阳/月亮 和 究极之日/究极之月 有官方简繁中文。
- 日版卡带通常只有日文；少数日版卡带内置多语言（如宝可梦 太阳/月亮、大乱斗等）。
- 美版/欧版卡带在日版机上不能直接运行，所以日版机想玩英文版，通常只能考虑改机或选择内置多语言的日版卡带。
- 不少游戏有民间汉化补丁（如怪物猎人 XX、勇者斗恶龙、火焰纹章等），但涉及改机和补丁操作，需要自行确认合规性。
