## 快速了解

- 关机后按住 **Select** 开机：进入 Luma3DS 配置页。
- 关机后按住 **Start** 开机：进入 GodMode9。
- 开机后同时按 **L + 下 + Select**：打开 Rosalina 菜单。
- 重要操作前先做 NAND 备份和存档备份。
- `movable.sed`、`boot9.bin`、NAND 备份等敏感文件不要上传或外发。
- 3DS 的 eShop 和官方联机服务已关停；本仓库不整理盗版下载指引。
