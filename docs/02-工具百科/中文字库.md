# 中文字库（日版机玩汉化游戏）

日版机的系统只有日文字库，而部分汉化游戏直接调用系统字库显示文字——不换字库就会出现缺字、方框、问号。本文讲清原理与安全用法。**不提供任何字库文件下载**，只整理流程。

## 原理

- 3DS 的系统字库按区域分版：日美欧一套、神游简体一套、港版繁体一套、韩版一套。日版机只内置日美欧字库。
- 汉化游戏（如《符文工房 4》《蘑菇队长》《朋友聚会》等）的文本引用系统字库字形；日版机缺中文字形，于是显示不全。
- 解法是用字库工具在**内存级别**把当前系统字库切换成中文字库（游戏进程读到的就是中文），退出/重启即还原，**不改系统文件**。

## ACG 字库工具（SharedFontTool）

一句话用途：ACG 汉化组出品的开源系统字库切换工具，在内存级别切换字库，让引用系统字库的汉化游戏正常显示中文。

- 开源仓库：[dnasdw/SharedFontTool](https://github.com/dnasdw/SharedFontTool)（已核实，最新 v3.1，2018-08 发布）。
- 两个版本：
  - `ACG_SFontT`：普通版，老三/新三通用。
  - `ACG_Big_SFontT`：80M 内存模式版，给老三的 mode3 大内存游戏用，用法与 BootNTR-Mode3 类似；新三上功能与普通版相同。配合方式见 [BootNTR与金手指.md](BootNTR与金手指.md)。

### 安装与使用

1. 把 SD 卡根目录放好 `font/` 文件夹（外置字库选项 7-10 需要它；只用内置字库可跳过）。
2. 用 FBI 安装 SFontT 的 `.cia`。
3. 启动工具，按菜单选字库：

| 选项 | 字库 |
| --- | --- |
| 0 | 全区字库（整合神游、港版、日版、美版、欧版） |
| 1 | 官方神游字库 mod 版（可用于韩版机） |
| 2 | 官方日美欧标准字库 mod 版（可用于神游机和韩版机） |
| 3 | 官方神游字库（简体） |
| 4 | 官方港版字库（繁体） |
| 5 | 官方日美欧标准字库（日版机日常用这个） |
| 6 | 官方韩版字库 |
| 7-10 | 外置字库（需自行在 SD 根目录 `font/` 放置对应字库文件） |

4. 切换后退出工具（按 START），再启动游戏即可。
5. 老三 mode3 游戏：先在桌面选好游戏（GW 需 SELECT 加载），启动 Big_SFontT 切字库，按 HOME 不结束应用、直接选游戏启动，提示切换应用时选「是」。为防误触退出 mode3，Big 版屏蔽了 START 直接退出。

## 注意事项 / 风险

- ⚠️ **安全的只有内存级切换**：SharedFontTool 这类工具不改系统文件。但「安装某些 CIA 替换系统字库」或「一键中文系统安装器」属于改写系统 NAND/HOME 菜单，是非常危险的操作——被这类安装器改过的机器，HOME 菜单可能被注入非原版代码，导致按原版固件制作的 LayeredFS 补丁**静默失效**（见 [14-坑与技巧.md](../01-系统折腾/14-坑与技巧.md)）。改之前务必先做 NAND 备份和 SD 卡全量备份。
- ⚠️ 用「外置字库」选项（7-10）时，字库文件来源要可靠，来源不明的 bcfnt 同样有风险。
- 字库切换后 HOME 菜单界面可能出现乱码，属正常现象，重启即恢复。
- 不是所有汉化游戏都需要字库工具：只改 ROM 内文本/字形的补丁（多数汉化版 CIA/LayeredFS 补丁）不依赖系统字库；只有「调用系统字库」的游戏才需要。
- 玩完需要日文字库的游戏时，记得把字库切回选项 5（日美欧标准）。
