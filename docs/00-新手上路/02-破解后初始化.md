# 破解后初始化清单

破解（B9S + Luma3DS）完成后，按下面顺序逐项执行。

## a. NAND 备份（最先做，一次就好）

- [ ] 关机 → 按住 **Start** 开机 → 进入 GodMode9
- [ ] 用 `GM9Megascript` → `Backup Options` → `SysNAND Backup`（或手动 `NAND Manager`），备份输出到 SD 卡 `/gm9/out/`
- [ ] 备份包含整盘 `.bin`（约 1.2GB）和 `essential.exefs`
- [ ] 把备份拷到电脑，**校验 SHA**（`.sha` 文件）并确认能解开
- [ ] 电脑和 SD 卡各留一份

⚠️ **不要沿用来源不明的旧备份**（时间戳异常、无法确认真实日期的备份一律重做）。

⚠️ GM9Megascript 的 `SysNAND Restore (safe)` 还原成功后会自动删除 SD 卡上的备份 `.bin`（电脑存档不受影响），属正常现象。

## b. 敏感文件备份

- [ ] SD 卡根目录的 `movable.sed`、`boot9.bin`
- [ ] GodMode9 备份目录里的 `essential.exefs`

⚠️ 这三类文件可以解密这台机器的全部系统数据：**不要上传网盘/GitHub/聊天群，不要发给任何人**。单独备份到电脑的加密目录，SD 卡上的副本收进安全文件夹。

## c. 安装基础工具

全部通过 FBI 安装 `.cia`（放 `/cias/` 目录）， `.3dsx` 版放 `/3ds/`。工具百科有各工具的详细页：

| 工具 | 作用 | 详见 |
| --- | --- | --- |
| FBI | 安装/管理 CIA、系统数据 | [../02-工具百科/FBI.md](../02-工具百科/FBI.md) |
| TYSS | 游戏存档备份与恢复（已替代 Checkpoint） | [../02-工具百科/TYSS.md](../02-工具百科/TYSS.md) |
| Universal-Updater | 自制软件应用商店（在线更新） | [../02-工具百科/Universal-Updater.md](../02-工具百科/Universal-Updater.md) |
| Anemone3DS | 主题与启动画面管理 | [../02-工具百科/Anemone3DS.md](../02-工具百科/Anemone3DS.md) |
| ftpd | SD 卡无线文件传输 | [../02-工具百科/ftpd与文件传输.md](../02-工具百科/ftpd与文件传输.md) |

- [ ] 五个工具全部装好并各打开一次确认能运行

## d. Luma 配置

- [ ] 关机 → 按住 **Select** 开机进入 Luma 配置页
- [ ] 勾选 **Enable game patching**（LayeredFS 补丁、区域模拟等的前提）→ **Save and exit**
- [ ] （按需）用 LumaLocaleSwitcher 给跨区游戏做区域模拟

⚠️ Luma v13 改配置必须选 **Save and exit** 才写入；只选 Boot chainloader 直接走，改动不保存（见 [../01-系统折腾/14-坑与技巧.md](../01-系统折腾/14-坑与技巧.md)）。

## e. 可选进阶

- CTRTransfer：换区、升降系统版本（会清除本机数据，先确认 a 步备份完好）
- 简体中文系统（日版机）：前置条件 Luma ≥ 10.3 + NAND 备份，流程见 [../01-系统折腾/11-简体中文系统.md](../01-系统折腾/11-简体中文系统.md)

## f. 验证清单

- [ ] 开机链正常：插卡开机直接进 HOME 菜单，无报错
- [ ] SELECT 开机 → Luma 配置页显示预期版本号
- [ ] Start 开机 → GodMode9 正常进入
- [ ] L + 下 + Select → Rosalina 菜单正常呼出
- [ ] 系统设置里版本号与预期一致
- [ ] SD 卡根目录有 `boot.firm`、`luma/`、`3ds/`、`gm9/` 等标准目录（参考 [../01-系统折腾/10-备份与恢复.md](../01-系统折腾/10-备份与恢复.md) 的 SD 卡现状）
