# 认识 3DS：基本信息科普

写给完全不了解 3DS 的读者。本文只回答"它是什么"：有哪些机型、系统版本是什么状态、版本机（区域）怎么分、买二手要注意什么。**动手折腾请直接看 [01-破解流程.md](01-破解流程.md)**，原理深入见 [../90-参考/91-原理与系统架构.md](../90-参考/91-原理与系统架构.md)，术语不熟先查 [03-术语表.md](03-术语表.md)。

> 3DS 是任天堂 2011 年推出的第八世代双屏掌机，下屏为触摸屏，上屏支持无需眼镜的裸眼 3D 显示，并向下兼容 Nintendo DS 卡带。全系列累计销量约 7594 万台。任天堂已于 2020 年 9 月停产整条产品线，eShop 与官方联机服务也已陆续关停——**现在入坑 3DS，基本等于入坑一台"官方已谢幕、社区正活跃"的机器**，折腾（破解）几乎是常态而非异类。

## 一、机型一览

3DS 全家族共 6 种机型，分"旧系"（初代硬件平台）和 "New 系"（2014 年起的中期强化平台）两代。

### 机型对比表

首发时间以最早发售地区为准；续航为任天堂官方标称（玩 3DS 游戏 / 玩 NDS 游戏，小时）。

| 机型 | 首发时间 | 上屏 | 下屏 | 3D 效果 | New 系 | 续航（3DS 游戏） | 形态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 3DS（原版） | 2011-02-26（日） | 3.53" | 3.0" | ✅ | ❌ | 3–5 h | 折叠 |
| 3DS XL / LL | 2012-07-28（日/欧） | 4.88" | 4.18" | ✅ | ❌ | 3.5–5.5 h | 折叠 |
| 2DS | 2013-10-12（美/欧） | 3.53" | 3.0" | ❌ | ❌ | 3.5–5.5 h | 直板（不折叠） |
| New 3DS | 2014-10-11（日） | 3.88" | 3.33" | ✅（人脸追踪） | ✅ | 3.5–6 h | 折叠，可换壳面板 |
| New 3DS XL / LL | 2014-10-11（日） | 4.88" | 4.18" | ✅（人脸追踪） | ✅ | 3.5–7 h | 折叠 |
| New 2DS XL / LL | 2017-07-28（美/欧） | 4.88" | 4.18" | ❌ | ✅ | 3.5–6.5 h | 折叠 |

补充说明：

- **LL 与 XL 是同一机型**：LL 是日本命名，XL 是欧美/韩版命名，硬件相同。
- **New 2DS XL 是最后发售的机型**（日版称 New 2DS LL，晚一天于 2017-07-29 发售）；全系于 2020-09-16 停产。
- 3DS 普通尺寸只在日本、欧洲、澳洲等地正式发售过；**北美只卖过限量版同捆的小 New 3DS**，常规渠道只有 XL。中国大陆行货只有"神游 3DS XL"（见第三部分）。
- 屏幕分辨率全家族一致：上屏 800×240（裸眼 3D 时左右眼各 400×240），下屏 320×240 电阻触控屏；XL 只是物理放大，像素密度反而更低。

### New 系升级了什么

| 项目 | 旧系（3DS / 3DS XL / 2DS） | New 系（New 3DS / New 3DS XL / New 2DS XL） |
| --- | --- | --- |
| CPU（ARM11） | 双核 268 MHz | 四核 804 MHz |
| 内存 | 128 MB | 256 MB |
| 操作 | 摇杆 + L/R | 增加 C 摇杆（指点杆）+ ZL/ZR 肩键 |
| amiibo / NFC | 需外置 NFC 读写器配件（2015 年发售） | 内置 NFC，直接刷 amiibo |
| 存储卡 | SD 卡 | microSD 卡（New 2DS XL 卡槽移至正面盖板下） |
| 3D 显示 | 固定视角裸眼 3D | Super Stable 3D：摄像头人脸追踪，视角更自由 |
| 独占内容 | — | 少数独占/强化游戏（如《异度神剑 3D》、New 3DS 专属 SFC 虚拟主机） |

### 对折腾的影响

两代平台的破解入口不同，**买机前先确认自己的机型**（最直接的区别：New 系上屏上方有内置摄像头用于人脸追踪、右肩键旁多一颗 ZL）：

| 机型 | 当前官方推荐入口（[3ds.hacks.guide](https://3ds.hacks.guide/get-started)） | 说明 |
| --- | --- | --- |
| New 3DS / New 3DS XL / New 2DS XL | **super-skaterhax**（浏览器漏洞） | 仅支持 New 系、系统 11.15.0+、全区域；成功率有随机性，失败重试即可 |
| 旧 3DS / 3DS XL / 2DS | **MSET9**（系统设置漏洞） | 需电脑跑 Python 脚本或 Android App；MSET9 本身全机型可用，New 系 super-skaterhax 多次失败时也转用它 |
| 全机型备选 | ntrboot | 需兼容的 DS 烧录卡（额外硬件），与系统版本完全无关 |

详见 [01-破解流程.md](01-破解流程.md) 与 [../90-参考/91-原理与系统架构.md](../90-参考/91-原理与系统架构.md)（入口漏洞会随系统更新失效，BootROM 层的 B9S 才是永久的）。

## 二、系统版本

### 最新版本

**截至 2026-10，3DS 最新系统版本是 11.17.0-50**（美版 2023-05-22 发布，日版 2023-05-23 发布），这也是任天堂官方更新历史中的最后一条记录，此后三年再无更新。[3ds.hacks.guide](https://3ds.hacks.guide/get-started) 的示例版本号同样停留在 11.17.0-50U。

版本号格式：`Ver. 11.17.0-50U` = 主版本.次版本.修订-内部版本 + **区域后缀**（J=日版、U=美版、E=欧版、K=韩版、T=台版、C=陆版），与锁区对应（见第三部分）。

关键事实：**最新系统版本也能破解**。11.17.0-50 这次更新封堵了当时多个可用的入口漏洞（这也是它被称作"惊喜更新"的原因），但 super-skaterhax / MSET9 等新入口随即被社区挖掘出来。所以"系统太新不能破"是老黄历——具体路线见 [01-破解流程.md](01-破解流程.md)。

### 官方服务关闭时间线

| 时间 | 事件 |
| --- | --- |
| 2022-05-23 | eShop 停止信用卡充值 |
| 2022-08-29 | eShop 停止点卡充值 |
| **2023-03-27** | **eShop 停止购买**（含免费内容、试玩版；兑换码于 2023-04-03 停止） |
| 2024-03-11 | NNID 与 Nintendo Account 余额合并停止 |
| **2024-04-08** | **在线联机等一切网络通信功能停止** |

来源：[任天堂官方 Q&A](https://en-americas-support.nintendo.com/app/answers/detail/a_id/57847/~/wii-u-%26-nintendo-3ds-eshop-discontinuation-q%26a)。注意两点：

- eShop 关闭后，**已购内容的重新下载和游戏更新在可预见的未来仍然可用**（任天堂原话 "for the foreseeable future"）。
- 联机停止不等于网络功能彻底死了：社区维护的 Pretendo 服务可以恢复联机与好友等功能，见 [../04-功能模块/46-联网对战.md](../04-功能模块/46-联网对战.md)。

## 三、区域版本（版本机）

3DS 是任天堂最后一代**严格锁区**的掌机，买机、买游戏、买充电器前都要先搞清楚区域。

### 区域码体系

| 区域码 | 销售区域 | 锁区归属 | 系统界面语言 |
| --- | --- | --- | --- |
| JPN | 日本 | 日本 | 仅日语（无语言选项） |
| USA | 北美（及中东、东南亚） | 北美 | 英语、法语、西班牙语、葡萄牙语 |
| EUR | 欧洲（含英国、澳洲） | 欧洲 | 英、法、德、西、意、荷、葡、俄 |
| KOR | 韩国 | 韩国 | 仅韩语（无语言选项） |
| TWN | 台湾/香港 | 台港 | 繁体中文（无语言选项；固件内残留未启用的英文） |
| CHN | 中国大陆（神游 iQue 行货） | 中国大陆 | 仅简体中文（无语言选项） |

锁区结论（核实过的要点）：

- **3DS 游戏卡带和数字版一律锁区**：日版机只能玩 JPN 游戏，美版机只能玩 USA 游戏，以此类推。锁区信息就写在每个游戏图标数据（SMDH）里，原理见 [../90-参考/91-原理与系统架构.md](../90-参考/91-原理与系统架构.md)。
- **NDS 游戏不锁区**：3DS 全家族都能跑任意区域的 NDS 卡带（个别 DSi 增强游戏仍受限），详情见 [../04-功能模块/45-NDS与GBA.md](../04-功能模块/45-NDS与GBA.md)。
- 破解（Luma3DS）后默认解除区域限制，可跨区运行游戏，所以**折腾玩家买机器时区域主要影响"系统界面语言"，而不是"能玩什么游戏"**。
- 陆版机比较特殊：行货神游 3DS XL（2012 年 12 月发售，由 iQue 发行）只能玩简体中文化的 CHN 区游戏，而 CHN 区阵容仅十余款（2 款预装 + 14 款可下载），且从未发行过实体卡带——这就是为什么国内玩家基本不买陆版机。
- New 系只发售过 JPN / USA / EUR / KOR 四个区域（官方换区用的 CTRTransfer 镜像也只提供这四个区域的 New 系版本）；CHN、TWN 仅有旧系机器。
- 台港市场 2015 年后改售带 "Jp" 标识的行货日版机（运行日版软件、网络功能受限），买台港二手时留意区分。

### 如何识别自己机器的区域

由易到难三种方法：

1. **看系统语言选项**（最快）：本体設定 → その他の設定 → 言語。只有日语 = 日版；有英/法/西/葡 = 美版（或中东/东南亚版）；有英/法/德/西/意/荷/葡/俄 = 欧版（或澳版）；只有韩语 = 韩版；无语言选项、系统繁中 = 台版；系统简中 = 陆版。
2. **看系统版本号后缀**：`Ver. 11.17.0-50J/U/E/K/T/C` 直接标出区域。
3. **看序列号前缀**（无需开机，下面详解）。

### 序列号规则

3DS 序列号格式为"**机型字母 + 区域字母 + 9 位数字**"，末位数字是 UPC 校验位，不是随机数。完整规则见 [3dbrew - Serials](http://www.3dbrew.org/wiki/Serials)（3DS 技术 wiki，本链接已实测可访问）：

**机型字母（第 1 位）**：

| 字母 | 机型 |
| --- | --- |
| C | 3DS（原版） |
| S | 3DS XL / LL |
| A | 2DS |
| Y | New 3DS |
| Q | New 3DS XL / LL |
| N | New 2DS XL / LL |

**区域字母（第 2 位起）**：

| 字母 | 销售区域 | 锁区归属 |
| --- | --- | --- |
| J* | 日本 | JPN |
| W | 北美 | USA |
| B | 巴西 | USA |
| S | 中东 / 东南亚 | USA |
| E* | 欧洲 | EUR |
| A* | 澳洲 | EUR |
| K* | 韩国 | KOR |
| C* | 中国大陆（神游） | CHN |

组合成"前缀 → 机型 + 区域"对照表（*号表示实际前缀由两个字母组成，如 JE/JF/JH/JM 都代表日版）：

| 前缀 | 机型 + 区域 | 备注 |
| --- | --- | --- |
| CJ* / CW / CB / CS / CE* / CA* / CK* | 3DS：日 / 美 / 巴西 / 中东东南亚 / 欧 / 澳 / 韩 | CW 是任天堂官方页面给出的美版 3DS 示例前缀 |
| SJ* / SW / SE* / SA* / SK* | 3DS XL/LL：日 / 美 / 欧 / 澳 / 韩 | |
| SC* | 3DS XL 神游行货（陆版） | 仅 CHN 区 |
| AW / AE* | 2DS：美 / 欧 | 日本长期不售 2DS，后期仅有少量限定同捆 |
| YJ* / YW / YE* / YK* | New 3DS：日 / 美 / 欧 / 韩 | 美版小 New 3DS 只有限量同捆 |
| QJ* / QW / QE* / QK* | New 3DS XL/LL：日 / 美 / 欧 / 韩 | 任天堂官方证实美版以 QW 开头 |
| NJ* / NW / NE* | New 2DS XL/LL：日 / 美 / 欧 | 任天堂官方证实美版以 NW 开头 |

注意：

- **台版（TWN）序列号前缀未见 3dbrew 收录**，本表不列出（未证实，建议以系统语言和版本号后缀为准）。
- 英国部分机器前缀中还会多出 "UH" 两个字母（3dbrew 记录的地方性变体）。
- 序列号只是识别手段，**不是防伪手段**：贴纸可以磨损、后盖可以换。验机时核对序列号与机器外观/区域是否自洽即可，具体见第四部分。

**序列号贴在哪儿**（任天堂官方说明，日版与美洲版页面互证）：

| 机型 | 序列号位置 |
| --- | --- |
| 3DS / 3DS XL / New 3DS XL | 机身背面（电池盖处）；部分机器电池仓内另贴一张 |
| 2DS | 机身背面（电池仓内另有一张） |
| New 3DS（小） | 拆下"きせかえ面板（上）"后可见的顶面 |
| New 2DS XL | 底部**卡槽盖内侧**（打开卡带仓盖可见） |

### 外观与硬件上的区域差异

- 语言与锁区是本质差异（见上表），外观差异主要是包装与说明书文字、电源插头制式；全家族充电器接口相同（与 DSi 通用），但插头形状随销售地区不同。
- 直板 2DS 无折叠、无 3D、单扬声器、带睡眠滑块，一眼可辨。
- 神游 iQue 3DS XL 为简体中文包装、大陆行货保修，机身外观与 3DS XL 一致，只能玩 CHN 区内容。
- 台港版机器（含 2015 年后的 "Jp" 日行机）包装有繁体中文标识。

### 为什么有人给非陆版机器装简体中文系统

只有陆版神游机原生简体中文，但它的游戏锁 CHN 区、阵容极少，没有折腾价值；日版机便宜量大、独占中文游戏多，但系统只有日语。于是社区做了**简体中文系统补丁**（LayeredFS 方式，把日版机的系统界面文字替换为简体中文），让日版机也能用上中文系统——这正是 [../01-系统折腾/11-简体中文系统.md](../01-系统折腾/11-简体中文系统.md) 的内容。破解后机器的游戏语言选择也更多，见 [../03-游戏与体验/30-游戏与汉化.md](../03-游戏与体验/30-游戏与汉化.md)。

## 四、买机 / 验机要点（二手）

3DS 早已停产，现在只能买二手。常见关注点：

| 坑 | 说明 | 应对 |
| --- | --- | --- |
| 翻新机 / 换壳机 | 外壳可整体更换，贴纸上序列号可能被磨掉重贴 | 看螺丝有无拧痕、外壳缝隙与色差；核对贴纸序列号前缀与机器实际区域（见第三部分）；序列号被改过可用自制工具检测，见 [../01-系统折腾/12-修改序列号.md](../01-系统折腾/12-修改序列号.md) |
| ban 机 | 任天堂历史上会对使用未授权软件/作弊的主机 ban 掉网络服务 | 官方服务 2024 年已全面停止，ban 的实质影响大减；联机改走 Pretendo（见 [../04-功能模块/46-联网对战.md](../04-功能模块/46-联网对战.md)），基本可忽略此项 |
| 屏幕"抽奖"（社区经验，非官方说法） | New 3DS / New 3DS XL 的上屏有 IPS 与 TN 两种面板混用，视角和色彩表现不同，俗称"屏幕抽奖"；New 2DS XL 普遍为 TN | 二手交易常把"双 IPS"当卖点加价；破解后可用自制工具 [3DSIdent](https://github.com/joel16/3DSIdent) 直接读出面板类型；斜看屏幕有无明显泛白也可粗判 |
| 屏幕老化 | 上屏 3D 功能故障、屏幕泛黄、亮线/坏点在这台十几年的机器上很常见 | 要求卖家实拍纯白/纯黑画面；3D 滑杆效果现场试 |
| 电池老化 | 原装电池普遍已衰减，续航打折、掉电快属常态 | 可低成本更换同规格电池；到手先实测续航 |
| 已有旧式破解 | 早年改机店机器可能残留旧式破解（A9LH/Gateway/来路不明的"中文系统"） | 不按新流程重来，先按 [3ds.hacks.guide](https://3ds.hacks.guide/get-started) 的 CFW 检查页升级处理；坑见 [../01-系统折腾/14-坑与技巧.md](../01-系统折腾/14-坑与技巧.md) |

到手后的正确顺序：**先不要系统更新、不要初始化**，按 [01-破解流程.md](01-破解流程.md) 检查是否已破解、完成破解与备份；二手数据清理见 [../01-系统折腾/10-备份与恢复.md](../01-系统折腾/10-备份与恢复.md)。
