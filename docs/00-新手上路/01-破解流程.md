# 破解流程：从原版机器到 B9S + Luma3DS

适用对象：系统版本 11.15–11.17（最新）的原版（stock）3DS 全系列机型。本文只写流程摘要和要点，**步骤细节以 [3ds.hacks.guide](https://3ds.hacks.guide/) 为准**，动手前请打开指南逐步对照。

## 当前推荐路线（截至 2026-10 核对）

3ds.hacks.guide 在 2026 年已改版：**SeedMiner 页面已被官方移除**（"被更好的漏洞取代"），不再需要显卡算力或在线算力服务。当前免费、免额外硬件的路线是：

| 机型 | 入口漏洞 | 说明 |
| --- | --- | --- |
| New 3DS / New 3DS XL / New 2DS XL | **super-skaterhax** | 浏览器漏洞，11.15.0+ 全区域可用；成功率有随机性，失败重试即可 |
| 旧 3DS / 3DS XL / 2DS | **MSET9** | 需要电脑跑 Python 脚本或 Android App，成功率更稳定 |
| 全机型备选 | ntrboot | 需要兼容的 DS 烧录卡（额外硬件） |

New 3DS 后续阶段：super-skaterhax → Homebrew Launcher → 运行 **nimdsphax** → **SafeB9SInstaller** → 安装 boot9strap → 开机自动进入 Luma3DS 配置页。

## 阶段一：准备工作

- [ ] 确认机器未破解：关机 → 按住 **Select** 开机，能进 Luma 配置页等自制菜单 = 已破解，不要重复操作
- [ ] 记录系统版本：本体設定 首页右上角（如 `Ver. 11.17.0-50J`）
- [ ] SD 卡格式化为 **FAT32**：官方只支持到 32GB，更大容量（如 64GB 卡）需在电脑上手动格式化为 FAT32，簇大小建议 32KB
- [ ] 准备 SD 读卡器（电脑 ↔ SD 卡传文件用）
- [ ] 电量充足（建议接充电器操作）
- [ ] 把 SD 卡原有内容在电脑上备份一份，防止中途变砖或数据损坏

⚠️ 破解完成前**不要系统更新、不要初始化/格式化主机**：保持指南验证过的版本，成功率最高。

## 阶段二：引导漏洞利用程序（进入 Homebrew Launcher）

- New 3DS：按指南下载对应区域和系统版本的 super-skaterhax 压缩包，解压到 SD 卡根目录；按页面要求临时调整区域设置和日期时间；用自带浏览器访问漏洞页面（日版为 `https://skater.686178.xyz/go/super`），按步骤清除浏览器存档、加书签、清 Cookie 后触发。失败会白屏报错，属随机失败，换语言或开关设置后重试（至多约十次仍失败则转 MSET9）。
- 旧 3DS：按 MSET9 页面用脚本在 SD 卡上布置漏洞文件，再在本体設定里触发。

## 阶段三：注入用户程序

- Homebrew Launcher 启动后，运行列表中的 **nimdsphax**，成功后直接进入 SafeB9SInstaller。
- 冻结在红/绿屏：按住电源关机后重试。

## 阶段四：安装 boot9strap

- 在 SafeB9SInstaller 中按上屏提示输入按键组合确认安装，装完按 (A) 重启。
- boot9strap 装在主机内部存储，**不依赖 SD 卡**，这也是现代破解与老破解（A9LH 时代）的本质区别。

## 阶段五：安装 Luma3DS

- 把 Luma3DS 压缩包里的 `boot.firm` 放到 SD 卡根目录（super-skaterhax/MSET9 的流程包里通常已含）。
- 重启后进入 Luma3DS 配置页，**保持默认选项不动**，按 (Start) 保存并重启。

## 阶段六：验证破解成功

- [ ] 关机 → 按住 **Select** 开机：出现 Luma3DS 配置页，第一行显示版本号（如 v13.4）→ 成功
- [ ] 正常开机进 HOME 菜单：外观与原版无异，但已在 CFW 下运行
- [ ] 按 **L + 下 + Select** 能呼出 Rosalina 菜单

完成后立刻进入 [02-破解后初始化.md](02-破解后初始化.md)：先做 NAND 备份，再装工具。

## ⚠️ 注意事项

- 破解全程不要中途断电、不要拔卡；按键组合确认类操作看清屏幕再按。
- NAND 备份要等破解完成后、动任何系统文件**之前**立刻做（GodMode9，详见 [02-破解后初始化.md](02-破解后初始化.md)）。
- 日版机破解后系统语言仍是日文，想换简体中文见 [../01-系统折腾/11-简体中文系统.md](../01-系统折腾/11-简体中文系统.md)。
- 二手机器如已有旧式破解（A9LH/menuhax/Gateway），不要按本文重来，先按指南的 Checking for CFW 升级到 B9S 方案。
- 踩坑记录先查 [../01-系统折腾/14-坑与技巧.md](../01-系统折腾/14-坑与技巧.md)。
