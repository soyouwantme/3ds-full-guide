# 术语表

3DS 折腾常见术语速查，按主题分组。含义列尽量一句话说清，详见列跳转到本仓库相关文档。

## 破解与引导

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| B9S（boot9strap） | 引导程序漏洞利用，开机时抢先加载自制固件，装在主机内部存储 | [01-破解流程.md](01-破解流程.md) |
| Luma3DS | 目前最主流的自制固件（CFW），以 SD 卡根目录 `boot.firm` 形式运行 | [../02-工具百科/Luma3DS.md](../02-工具百科/Luma3DS.md) |
| CFW（Custom Firmware） | 自制固件，修改过的系统软件，可运行自制程序、无视区域锁、打补丁 | [01-破解流程.md](01-破解流程.md) |
| FIRM | 3DS 的固件镜像格式，系统启动的核心组件 | [01-破解流程.md](01-破解流程.md) |
| SafeB9SInstaller | 安装 boot9strap 的引导程序，破解流程中的安装界面 | [01-破解流程.md](01-破解流程.md) |
| Homebrew Launcher（HBL） | `.3dsx` 自制程序启动器，是破解流程进入漏洞程序的跳板 | [../02-工具百科/HomebrewLauncher.md](../02-工具百科/HomebrewLauncher.md) |
| super-skaterhax | New 3DS 系 11.15+ 的浏览器入口漏洞（当前官方推荐） | [01-破解流程.md](01-破解流程.md) |
| MSET9 | 旧 3DS 系的入口漏洞，需电脑脚本或 Android App 布置 | [01-破解流程.md](01-破解流程.md) |
| SeedMiner | 旧式入口方案：用 movable.sed 的密钥派生破解入口，**已被官方指南移除** | [01-破解流程.md](01-破解流程.md) |
| movable.sed | 本机独有的密钥文件，可解密本机全部数据，极度敏感 | [02-破解后初始化.md](02-破解后初始化.md) |
| ID0 | SD 卡 `Nintendo 3DS/` 下由 movable.sed 派生的 32 位十六进制目录名 | [../01-系统折腾/10-备份与恢复.md](../01-系统折腾/10-备份与恢复.md) |
| ntrboot | 用 DS 烧录卡引导的备用破解入口，需额外硬件 | [01-破解流程.md](01-破解流程.md) |

| 术语 | 含义 | 详见 |
| --- | --- | --- |

| emuNAND | 把系统搬到 SD 卡上运行的旧方案，现已基本淘汰 | [../01-系统折腾/10-备份与恢复.md](../01-系统折腾/10-备份与恢复.md) |
| essential.exefs | GodMode9 备份生成的精简关键文件包，比整盘备份小得多 | [02-破解后初始化.md](02-破解后初始化.md) |
| CTRTransfer | 用 GodMode9 整体替换系统固件的操作，可换区、升降版本 | [../01-系统折腾/10-备份与恢复.md](../01-系统折腾/10-备份与恢复.md) |
| TWL_FIRM | 负责运行 NDS 软件（TWL 模式）的固件组件 | [../04-功能模块/45-NDS与GBA.md](../04-功能模块/45-NDS与GBA.md) |
| AGB_FIRM | 负责运行 GBA 原生模式（Virtual Console）的固件组件 | [../04-功能模块/45-NDS与GBA.md](../04-功能模块/45-NDS与GBA.md) |

## 补丁与扩展

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| LayeredFS | Luma 的透明文件替换机制：SD 卡上的文件覆盖系统/游戏内文件，汉化补丁的主要实现方式 | [../01-系统折腾/11-简体中文系统.md](../01-系统折腾/11-简体中文系统.md) |
| game patching | Luma 配置项，开启后才启用 LayeredFS、区域模拟等补丁功能 | [02-破解后初始化.md](02-破解后初始化.md) |
| Rosalina | Luma 内置的系统菜单（L + 下 + Select 呼出），可截图、调亮度、挂载进程 | [../02-工具百科/Luma3DS.md](../02-工具百科/Luma3DS.md) |
| NTR | 内存补丁/金手指框架，以 `BootNTRSelector` 形式使用，游戏内 Y+X 呼出菜单 | [../02-工具百科/BootNTR与金手指.md](../02-工具百科/BootNTR与金手指.md) |
