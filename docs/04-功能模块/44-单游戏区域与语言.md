# 单游戏区域与语言模拟

让**某一个游戏**以为自己运行在指定区域、指定语言的机器上，而不影响机器上其他游戏和系统本身。配置由 Luma3DS 在加载该游戏时读取，全程不改系统、不改游戏本体。

## 为什么会有这个需求

3DS 是任天堂最后一代严格锁区的掌机：游戏卡带和数字版按 JPN / USA / EUR 等区域发行，破解（Luma3DS）后虽然默认解除了"能不能运行"的限制，但游戏启动时仍会向系统询问"我是什么区域、该说哪种语言"，于是出现几类典型烦恼：

- **默认语言猜错**：欧版机跑美版游戏，游戏按系统区域推断默认语言，可能落到你不想要的语言上；多语言游戏（如美版内置英/法/西）想固定其中一种也没办法。
- **跨区游戏水土不服**：日版机跑美版卡带、欧版机跑日版游戏，少数游戏会启动崩溃、ErrDisp 报错，或字体/语言显示异常——它读到的区域信息和预期不符。
- **想练外语**：给单个游戏指定英文、日文等语言，沉浸式学习，而其他游戏保持原样。
- **日版单语言游戏**：日版游戏大多只内置日语资源，此时任何模拟都变不出第二种语言（见下文注意事项）。

区域版本（版本机）的背景知识——区域码体系、各区域系统语言、锁区规则——见 [00-认识3DS.md](../00-新手上路/00-认识3DS.md) 第三部分。

## 能干什么

| 场景 | 说明 |
| --- | --- |
| 固定某个游戏的语言 | 多语言游戏强制以英/法/日等指定语言启动，不被系统区域带偏 |
| 修复跨区游戏的启动报错 | 外区游戏崩溃、ErrDisp 时，模拟它原生区域的运行环境 |
| 修复字体/显示异常 | 跨区游戏内文字体错乱、界面语言错乱时纠正 |
| 外语学习 | 只给学习用的一两个游戏切语言，其余游戏和系统不受影响 |

## 原理与注意事项

### Luma 的 per-game 模拟是怎么工作的

这是 Luma3DS **game patching** 能力的一部分：Luma 在 loader 层加载游戏时按 TitleID 查找补丁目录，其中 `luma/titles/<TitleID>/locale.txt` 就是区域/语言模拟配置（格式如 `JPN JP`、`USA EN`）。要点：

- **按游戏隔离**：每个游戏一份 `locale.txt`，只对写明了 TitleID 的那个游戏生效；其他游戏、系统界面完全不受影响。
- **不修改任何本体**：配置躺在 SD 卡的 `luma/titles/` 下，游戏文件、系统固件一个字节都不动；删掉配置即恢复原行为。
- **生效前提**：Luma 配置页的 *Enable game patching* 和 *Enable region/language emulation via .txt files* 都已开启，否则配置被静默忽略。

Luma 在系统哪一层打这个补丁、为什么区域锁判断能被这样改写，原理细节见 [91-原理与系统架构.md](../90-参考/91-原理与系统架构.md) 和 [Luma3DS](../02-工具百科/Luma3DS.md) 的 game patching 一节。

### 和整机换区（CTRTransfer）的本质区别

| | 单游戏区域/语言模拟 | 整机换区（CTRTransfer） |
| --- | --- | --- |
| 改动对象 | SD 卡上一个文本配置 | CTRNAND 里整套系统 Title + FIRM |
| 影响范围 | 仅单个游戏 | 整台机器的系统区域与界面语言 |
| 风险 | 无，删文件即还原 | 高，属重装系统级操作，必须先有 NAND 备份 |
| 适用 | 修个别游戏、练外语 | 想彻底改变机器区域（如欧版机整体变日版） |

CTRTransfer 会替换 NAND 里的整套系统，操作前必须有完好的 NAND 备份，备份方法与风险说明见 [备份与恢复](../01-系统折腾/10-备份与恢复.md)；它替换 CTRNAND 的原理见 [91-原理与系统架构.md](../90-参考/91-原理与系统架构.md)。**只想解决个别游戏的语言/区域问题，永远选本文的轻量方案，不要动 CTRTransfer。**

### 配置文件长什么样

每个被设置过的游戏，SD 卡上对应这样一个文件（由工具自动生成，一般不需要手写）：

```
luma/titles/<16位TitleID>/
└── locale.txt    # 内容形如 "JPN JP"、"USA EN"，即 "区域 语言"
```

它和汉化补丁、金手指等 game patching 产物共用同一个 `luma/titles/<TitleID>/` 目录，互不冲突；备份 SD 卡时这些配置随卡一起走。

### 常见误区

- **"模拟成日版就能玩日版游戏了？"**——不能，也不需要。Luma 破解后已默认解除区域锁，任何区域的机器本来就能运行任何区域的游戏；locale 模拟管的是游戏启动后"认为自己在什么环境"（默认语言、字体、区域校验等），不负责放行。
- **"给游戏设成中文就能出中文？"**——不能。游戏要内置中文资源才会有中文，模拟只是把选择权从"按系统区域猜"改成"按你的指定来"，无中生有做不到。
- **"换机器/换 SD 卡配置还在吗？"**——配置写在 SD 卡上、按 TitleID 绑定游戏，不绑定机器；同一张卡插到另一台破解机上，同一游戏照样按配置运行。

### 其他注意事项

- **只对有对应语言资源的游戏有效**：模拟语言 ≠ 给游戏加语言。游戏没内置该语言资源时，设什么都不会变（日版单语言游戏即如此）；反过来，游戏内置了资源但锁了默认语言时，模拟才有意义。
- **配置随游戏 Title 走**：locale 配置按 TitleID 绑定。更新游戏、重装游戏一般不影响；但同一个游戏的**不同版本/不同区域版本是不同 TitleID**，配置不能互相套用。
- **典型症状才需要它**：跨区游戏崩溃、ErrDisp、语言/字体异常才设置；机器和游戏同区且语言正常时（如日版机玩日版游戏）完全不需要。
- 设置后不生效时，先按 [LumaLocaleSwitcher](../02-工具百科/LumaLocaleSwitcher.md) 的排查清单确认 game patching 已开启、`locale.txt` 确实存在。

## 推荐流程

1. 确认 Luma3DS 已安装，且配置页的 game patching 与区域语言模拟选项已开启（开启方法见 [Luma3DS](../02-工具百科/Luma3DS.md)）。
2. 安装并启动 [LumaLocaleSwitcher](../02-工具百科/LumaLocaleSwitcher.md)，进入游戏列表找到目标游戏。
3. 为该游戏设置需要的区域和语言，保存（工具会自动生成对应的 `locale.txt`）。
4. 回到 HOME 菜单重新启动该游戏，按模拟的区域/语言运行；不对就换组合重设。
