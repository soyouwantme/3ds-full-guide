# Pretendo 联机设置（3DS / Nimbus）

3DS 接入 Pretendo Network 的完整步骤。Pretendo 是社区维护的开源替代服务，用来恢复 3DS/Wii U 已关闭的官方联机功能（游戏联机、Miiverse 替代 Juxtaposition、好友、排行榜等）。

> 本文基于官方文档 [pretendo.network/docs/install/3ds](https://pretendo.network/docs/install/3ds) 与 Nimbus v2.1.1 Release 压缩包结构整理。

## 原理（3DS 不需要改 DNS）

- 3DS 端用的是 **Nimbus**：它利用 3DS 系统里未使用的"第二本地账号"功能，创建一个 `test` NASC 环境的本地账号。
- SD 卡上的 **IPS 补丁**把 `test` 环境的 URL 全部指向 Pretendo 服务器。
- 因此 3DS 上**不用像 Wii U 那样改 DNS**，用 Nimbus 在 Pretendo / Nintendo 之间一键切换即可，选择会持久保存。

## 前提条件

- 自制系统：已破解（boot9strap + Luma3DS v13.0 或更新）
- 启动方式：启动 sysNAND（emuNAND 也可以）
- Luma 配置：`Enable loading external FIRMs and modules` 开启
- Luma 配置：`Enable game patching` 开启
- 网络：3DS 能连上互联网

## 第一步：下载 Nimbus

- GitHub Release：<https://github.com/PretendoNetwork/nimbus/releases>（最新 v2.2.0，2025-10；2026-10-11 已实测安装）
  - `combined.2.2.0.zip`：3DSX + CIA + 全部补丁（推荐）
  - `3dsx.2.2.0.zip`：仅 3DSX（走 Homebrew Launcher）
  - `cia.2.2.0.zip`：仅 CIA（走 HOME 菜单）
- 也可以在机器上装 **Universal-Updater**，搜索 `Nimbus` 直接安装（首次仍需手动放 IPS 补丁，之后可全在机器上更新）。

## 第二步：解压到 SD 卡

关机，取出 SD 卡插电脑，把 `combined.2.2.0.zip` 解压到 **SD 卡根目录**，提示合并/覆盖就接受。

解压后应存在以下文件（v2.2.0 压缩包实际结构，与 v2.1.1 相同）：

```
3ds/
├── nimbus.3dsx                          # 3DSX 程序（Homebrew Launcher 用）
└── nimbus/
    └── update/
        ├── 000400300000BC02.ips         # Miiverse（JPN）
        ├── 000400300000BD02.ips         # Miiverse（USA）
        ├── 000400300000BE02.ips         # Miiverse（EUR）
        ├── 0004013000002902.ips         # HTTP
        ├── 0004013000002E02.ips         # Sockets
        ├── 0004013000002F02.ips         # SSL
        ├── 0004013000003202.ips         # FRD / 好友
        ├── 0004013000003802.ips         # ACT / NNID
        ├── juxt-prod.pem                # Juxtaposition 证书
        ├── nimbus.3gx                   # Luma 3GX 插件
        └── update.txt
cias/
└── nimbus.cia                           # 安装到 HOME 菜单用（可选）
```

## 第三步：确认 Luma 补丁开关

关机后**按住 Select 再开机**进入 Luma 配置页，确认以下两项都开着：

- `Enable loading external FIRMS and modules` ⚠️（最容易漏开的一项，务必确认）
- `Enable game patching`

按 **Start** 保存并继续启动。

## 第四步：安装 Nimbus 到 HOME 菜单（可选）

如果用的是 combined 或 cia 包：

1. 打开 **FBI**。
2. 进入 `SD` → `cias`，选择 `nimbus.cia`。
3. 选 `Install CIA` 或 `Install and delete CIA`。
4. 回 HOME 菜单，会提示新增应用，Nimbus 就在 HOME 上了。

> 如果只用 3DSX 版，则从 Homebrew Launcher 启动 `nimbus.3dsx`。

## 第五步：启动并启用插件

1. 启动 Nimbus（HOME 菜单图标或 Homebrew Launcher）。
2. 选择 **Pretendo** 或 **Nintendo** 切换服务；选择会跨重启保存。
3. **开机后按 L + 下 + Select** 打开 Rosalina 菜单，把 **Plugin Loader** 设为 **Enabled**（Nimbus 的 3GX 插件需要它，游戏内才会走 Pretendo 补丁）。

## 第六步：创建 PNID（账号）

- 3DS 上创建 PNID 的方式和 NNID 完全一样：**系统设置 → Nintendo Network ID 设置**。
- **推荐直接在机器上创建**：官网注册的账号目前是占位资料，无法修改用户信息。
- ⚠️ **PNID 用户名不能和机器上已关联的 NNID 用户名相同**，要另取一个名字。
- 大多数游戏的联机**不需要 PNID** 也能玩；PNID 主要用在 Juxtaposition（Miiverse 替代）、部分需要账号的操作上。

## 注意事项（官方 CAUTION）

- ⚠️ **不要为了装 Pretendo 删除 NNID**：会丢掉徽章、可重新下载的游戏、主题和宝可梦银行数据。
- ⚠️ **Pretendo 暂不支持系统转移（System Transfer）**，强行操作可能导致以后无法联网。
- ⚠️ **Nintendo Badge Arcade 暂不支持**：不要开，徽章数据在 Pretendo / Nintendo 两个网络间不互通，来回切换会让徽章消失（补救：Simple Badge Injector + Advanced Badge Editor，见官方文档）。
- 想切回任天堂官方网络时，用 Nimbus 选回 Nintendo 即可。

## 常见问题排查

### 切换 Pretendo 报 d8a0c4ef（switch account failed）

**症状**：Nimbus 里选 Pretendo 报 `switch account failed with error: d8a0c4ef`，或变体 `unload friends account failed with error: d8a0c4e5`。

**原因**：系统的 ACT / 好友账号服务处于半切换状态，Nimbus 卸载旧账号失败。**这个错误可能意味着切换不完整**——之后即使不再报错，联机也可能实际没走 Pretendo，要进游戏实测验证。

**修复**（按顺序尝试）：

1. **直接重启机器**，重开 Nimbus 再切一次（多数情况重启即好，见 [Pretendo 论坛案例](https://forum.pretendo.network/t/nimbus-problem-with-new-2ds-xl/25932/4)）。
2. 还报错：关机 → **按住 Select 开机**进 Luma 配置 → 确认 `Enable loading external FIRMs and modules` 和 `Enable game patching` 都开启（Nimbus [README](https://github.com/PretendoNetwork/nimbus) 的官方排查步骤）→ Start 保存。
3. 仍报错：Nimbus 切回 **Nintendo** → 打开 eShop 等到加载画面消失（让账号服务完全初始化）→ 退出 eShop → 回 Nimbus 切 **Pretendo**（见 [法国玩家经验](https://lyonocr.fr/pretendo-cest-quoi-t-est-ce/)）。
4. 切完后重启机器，进联机游戏实测；不成就重复上面流程。

### NNID 设置显示 022-5432、要求重新登录，且没有退出选项

**症状**：切换 Pretendo 前已登录过 NNID，切到 Pretendo 后本体设定的 NNID 设置页仍停留在旧账号状态，报 **022-5432** 并要求输入密码，Nimbus 里 Unlink 提示"没有 PNID"。

**原因**：3DS 的 NNID 设置页本来就没有"退出登录"按钮（只有新建/删除）；且这是 Nimbus 的**已知 bug**（[issue #32](https://github.com/PretendoNetwork/nimbus/issues/32)）：首次切换后 ID 部分可能没切干净，设置页还连着旧 NNID 状态。

**修复**：打开 Nimbus 切到 **Nintendo** → 再切回 **Pretendo**。一次不行就多切几次（有人连续切两次 Pretendo 才生效），直到设置页出现「新規作成」。开发者确认此 bug 暂无根治方案，多切几次是正常操作。

**注意**：别在报错界面输 NNID 密码，没用；更别用设置里的「ID削除」删 NNID，会永久丢失徽章/可重下载游戏/宝可梦银行数据。

### 想解除已绑定的 PNID

Nimbus **v2.1.0 起内置 Unlink PNID 按钮**：打开 Nimbus 按该按钮即可解绑。旧版本才需要"关 Luma 前两项 → Miiverse 看 022-5432 → 重开 → eShop → 015-5015"的老办法。

### 其他已知坑

- **PNID 用户名不能和机器上的 NNID 相同**，否则登录永远失败
- **密码重置不能在 3DS 上操作**（Pretendo 已知 bug），要去官网 account.pretendo.network
- 密码建议别用特殊符号（3DS 输入法对部分特殊字符支持有问题）
