# 文件传输：电脑 ↔ 3DS

把文件从电脑弄进 3DS 的 SD 卡（或反向导出），是所有折腾的地基：装自制程序、传主题、备份存档都要先过这一关。本文对比四种传输方案、讲清文件该传到哪个目录，并按场景给出推荐流程；各工具的安装与具体操作见 [02-工具百科](../02-工具百科/README.md)。

## 能干什么：四种传输方案对比

| 方案 | 适用场景 | 优点 | 局限 | 前置条件 |
| --- | --- | --- | --- | --- |
| SD 卡拔卡 + 读卡器 | 首次配置、大批量拷贝、整卡备份 | 速度最快、最稳定，不依赖网络和电量 | 要关机拔卡；老机型卡槽在电池仓内，插拔麻烦 | 电脑有 SD 读卡器（USB 或机身卡槽） |
| ftpd 无线 FTP | 日常小文件：主题包、存档、补丁、零星 CIA | 免拔卡，3DS 放一边就能传 | 速度受 Wi-Fi 限制，大文件很慢；传输可能中断需重试 | 电脑和 3DS 连**同一个 Wi-Fi**；3DS 端已装 [ftpd](../02-工具百科/ftpd与文件传输.md) |
| Tulip3DS 无线直装 | 在电脑上试玩验证后，把 CIA 直接推送安装到 3DS | 电脑端自带 3DS 模拟器可先行验证，推送即装，省"传文件 + 开 FBI"两步 | 仅适合装 CIA；环境与真机仍有差异，模拟能跑不等于真机完美 | 同一局域网；3DS 端装有配套的 Client/Installer（见 [工具总表](../02-工具百科/README.md) 的 Tulip3DS 条目） |
| 3DSort FTP 桥 | 不拔卡远程整理 HOME 菜单：拖拽图标、建文件夹、排序 | 在电脑大屏幕上编辑布局，带实机屏幕预览；同步前自动校验文件大小 | 只同步布局等系统数据，游戏本体和存档不动；流程环节较多 | 同一 Wi-Fi + 3DS 端 ftpd + GodMode9 脚本（流程见 [ftpd与文件传输](../02-工具百科/ftpd与文件传输.md) 的 3DSort 一节） |

一句话选型：**备一张读卡器保底，日常小文件走 ftpd，批量装游戏按需用 Tulip3DS，整理图标用 3DSort**。

传输是双向的，除了往 3DS 里拷，经常还要从 3DS 取东西回电脑：

- **存档**：TYSS 导出的存档包，用 ftpd 下载或拔卡从 `/TYSS/` 取（存档管理见 41-存档管理）。
- **系统备份产物**：GodMode9 的 NAND 备份、essential 文件输出在 `/gm9/out/`，体积大，建议拔卡拷贝（备份清单见 [备份与恢复](../01-系统折腾/10-备份与恢复.md)）。
- **照片和截图**：系统拍照在 `/DCIM/`，金手指截屏按各自工具的输出目录找。
- **主题、徽章等成品**：Anemone3DS 可以把自己做的主题打包导出再传回电脑。

## 注意事项：文件该传到哪个目录

SD 卡根目录各位置的分工（完整目录表见 [备份与恢复](../01-系统折腾/10-备份与恢复.md)）：

| 路径 | 放什么 |
| --- | --- |
| SD 卡根目录 | `boot.firm`、`boot.3dsx` 等引导文件，以及待安装的 `.cia`（惯例放 `/cias/`） |
| `/3ds/` | `.3dsx` 自制程序（ftpd、GodMode9 脚本工具等） |
| `/luma/` | Luma 配置、区域模拟、LayeredFS 补丁文件 |
| `/gm9/` | GodMode9 脚本；`/gm9/out/` 是它的备份输出位置 |
| `/Themes/`、`/badges/` 等 | 主题、徽章等资源，由对应管理工具读取 |
| `/Nintendo 3DS/<ID0>/<ID1>/` | 系统管理的区域：已安装游戏内容（`title/`）、存档、主题/徽章数据（`extdata/`） |

**`/Nintendo 3DS/` 里的东西不要手动往里拷游戏或存档**：这一层由系统按 TitleID 组织并加密，正确入口是 FBI 装 CIA、TYSS 导存档（存档备份另有专篇，见 [备份与恢复](../01-系统折腾/10-备份与恢复.md)）。你要传的东西 99% 落在根目录或 `/3ds/`、`/cias/` 这类明文字典里。

**为什么路径看起来乱**：`<ID0>` 是由本机主密钥 `movable.sed` 派生的一长串十六进制目录名，`<ID1>` 又由 SD 卡自身的卡序列号派生——所以这两层名字既不是乱码也"认人认卡"：插回同一台机器同一张卡就一切正常，换卡后系统会按新 ID1 重建目录，旧数据看着像"消失"了其实还在。这两段目录名的来历和加密原理见 [91-原理与系统架构.md](../90-参考/91-原理与系统架构.md) 的"存储结构"一节；换卡、清卡的正确姿势见 [备份与恢复](../01-系统折腾/10-备份与恢复.md)。

## 注意事项：macOS 特有坑

- ⚠️ **不要往 SD 卡里写 macOS 元数据**：用访达拷贝会顺带生成 `.DS_Store` 和 `._*`（AppleDouble 资源分支）文件。3DS 自制软件大多能忽略它们，但会污染目录、干扰逐文件校验，个别工具按文件列表处理时会出错。传输后可用 `find /Volumes/卡名 -name '.DS_Store' -delete -o -name '._*' -delete` 清理。
- ⚠️ **访达的 FTP 连接是只读的**：⌘K 连 `ftp://` 只能浏览下载，不能上传/删除。要无线写入就用 FileZilla 或命令行 curl（命令模板见 [ftpd与文件传输](../02-工具百科/ftpd与文件传输.md)）。
- 拔卡拷贝尽量用 `cp -X` 或 rsync（不带资源分支），从源头避免 `._*` 文件生成。
- FTP 删除是永久删除，不进回收站；大文件传完务必等 ftpd 正常退出落盘再动 SD 卡。

## 推荐流程

四个场景互相独立，对号入座即可；只有场景 A 建议人人必做，其余按需要选择。

### 场景 A：首次配置 / 大批量 / 整卡备份

1. 关机拔卡，插电脑读卡器；整卡备份（含隐藏文件）按 [备份与恢复](../01-系统折腾/10-备份与恢复.md) 的清单执行。
2. 把 `boot.firm`、`/luma/`、`/3ds/`、`/cias/` 等一次性拷入，完成 [破解后初始化](../00-新手上路/02-破解后初始化.md)。
3. 回插 3DS 验证能开机、工具齐全，之后日常小文件就不必再拔卡了。

### 场景 B：日常传小文件（主题、存档、补丁）

1. 3DS 和电脑连同一个 Wi-Fi，3DS 上启动 ftpd，记下屏幕显示的 IP:端口。
2. 电脑端用 curl 或 FileZilla 上传/下载/删除（命令与客户端注意事项见 [ftpd与文件传输](../02-工具百科/ftpd与文件传输.md)）。
3. 传完按 HOME 正常退出 ftpd 落盘，再去对应工具（如 Anemone3DS）里确认文件生效。

### 场景 C：批量安装 CIA

- 文件少：走场景 B 把 `.cia` 传到 `/cias/`，3DS 上用 [FBI](../02-工具百科/FBI.md) 安装。
- 想先在电脑上验证再装：用 Tulip3DS 的模拟器跑一遍，确认无误后无线推送直装（环境与留档见 [工具总表](../02-工具百科/README.md) 的 Tulip3DS 条目）。

### 场景 D：整理 HOME 菜单图标（建文件夹、排序）

1. 3DS 开 ftpd → 电脑端 pull 拉取镜像 → 打开 3DSort 拖拽编辑。
2. push 回传 → 关机进 GodMode9 跑 inject 脚本 → 重启生效。
3. 全程红线与逐步操作见 [ftpd与文件传输](../02-工具百科/ftpd与文件传输.md) 的 3DSort 一节；该流程只动布局数据，游戏和存档不受影响。
