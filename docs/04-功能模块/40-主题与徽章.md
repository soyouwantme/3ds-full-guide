# 主题与徽章

主题（Theme）是给 3DS HOME 菜单换的整套界面皮肤：背景、文件夹、图标样式、音效和背景音乐（BGM）一起换掉，全部由社区玩家制作分享。配合启动画面（boot splash）和徽章（badges），可以把整机外观从头到脚个性化。

## 能干什么

| 功能 | 是什么 | 典型场景 |
| --- | --- | --- |
| 主题 | HOME 菜单的整套界面皮肤，含贴图与 BGM | 厌倦了官方几个默认主题，想换成游戏/动漫风格的界面 |
| 启动画面 | 开机时 Luma3DS 显示的自定义图片 | 开机第一屏个性化，展示个性签名图 |
| 徽章 | HOME 菜单图标旁摆放的小装饰图 | 装饰游戏图标、拼贴摆图，替代官方途径收集 |
| 自定义制作 | 用在线工具自己出图配 BGM 做主题 | 想要独一份、社区站点上没有的界面 |

三个概念别混淆：

- **主题**作用于 HOME 菜单本身（系统界面），重启后依然生效，是整个外观的核心。
- **启动画面**只在开机的一瞬显示，属于引导层（Luma3DS）的装饰，与 HOME 菜单主题互不相干，可以单独装、单独换。
- **徽章**是摆在 HOME 菜单图标位置的小图片，不参与界面皮肤，数量上可以自由收集摆放。

三者可以任意组合：只换主题、只加开机画面、或者主题 + 启动画面 + 徽章全套都用，互不影响。

除了单纯换皮，常见玩法还有：

- **多主题轮换**：一次装好几套主题，设置轮换后定期自动换肤，一台机器当几台用。
- **扫码即装**：Theme Plaza 上的部分作品带二维码，用 Anemone3DS 直接扫码下载安装，省去电脑传文件的步骤。
- **自己做主题**：有现成的在线主题制作工具，自己出图、配 BGM 就能做出独一份的主题，做完导出文件同样走安装流程。
- **备份与迁移**：把已装的主题包和徽章备份留在电脑上，换 SD 卡、换机或重装时直接还原，收藏不丢。备份方法见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。

## 主题从哪来

主题、启动画面、徽章都有成熟的社区分享生态，玩家制作好后上传到社区站点供他人下载。最知名的是 **Theme Plaza**，上面聚合了海量社区作品（主题为主，也有启动画面和徽章），通常带预览图，部分作品还提供二维码可直接扫码安装。站内作品为社区投稿，质量与兼容性参差，下载前先看预览和评论。官网：[Theme Plaza](https://themeplaza.art/)（2026-10 验证可访问）。

挑选时留意作品页面标注的适用系统版本和区域，与自己机器对不上就别硬装；老作品优先看评论区有没有"更新后还能用"的反馈。

除 Theme Plaza 外，各社区论坛、聊天群组里也有作者自发分享作品，文件格式相同，安装方式一致。社区站点只负责分发文件，本身不涉及任何系统修改；把文件装上机器这一步由 Anemone3DS 完成。

## 徽章与 Plaza 的关系

徽章最初是任天堂官方玩法的一部分：通过 **Nintendo Badge Arcade**（徽章抓娃娃机）和 **StreetPass Mii Plaza**（擦肩 Mii 广场）等 Plaza 类应用获取，用来装饰 HOME 菜单图标。这些官方服务依托于已关停的 3DS 网络生态，如今新徽章基本只能靠社区分享的文件自行安装。

Anemone3DS 支持导入这些社区徽章文件，也支持把机器上已有的官方徽章备份导出，换新机或重装时不会丢。徽章的目录组织、数量上限和备份方法见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。

## 注意事项 / 原理

- **前置是 CFW**：主题/启动画面/徽章的加载依赖 Luma3DS 的补丁机制，未破解的原版机器无法使用。破解流程见 [01-破解流程](../00-新手上路/01-破解流程.md)。
- **兼容性看系统版本与区域**：社区主题多为特定系统版本制作，系统大版本更新后旧主题可能出现贴图错位、HOME 菜单起不来等问题；部分主题按区域（日/美/欧）制作，跨区使用可能布局异常。遇到 HOME 菜单起不来，卸载当前主题即可恢复，详细救法见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
- **系统刚大版本更新时缓一缓**：社区主题跟进系统更新有滞后，更新后先等常用主题确认兼容再换，别第一时间拿旧主题往上套。
- **预览不等于实机**：Anemone3DS 里的预览图和实际效果可能有出入，尤其是 BGM 和动效部分；批量下载前建议先装一两套试试水。
- **徽章有上限、装新会覆盖旧的**：整机徽章数量有硬性上限，且安装新徽章可能覆盖已有徽章，动手前先备份。规则细节见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
- **占用 SD 卡空间**：每套主题含贴图和 BGM，徽章和启动画面也是文件。装得多 + 留着轮换收藏，几十上百 MB 很正常，SD 卡紧张时优先清理不用的主题包。
- **别一次装太多**：主题和徽章的收藏欲容易一发不可收拾，按常用常换的原则留存，定期清理，机器列表也更清爽。
- **换主题不影响系统功能**：主题只是界面皮肤，与游戏存档、系统设置互不影响；不用时随时可还原默认官方主题。
- **还原默认很简单**：卸载已装主题（在 Anemone3DS 中操作）或在系统设置的主题列表里切回官方默认主题即可；机器本身的任何数据都不会丢。操作见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
- **想自己做主题**：社区有在线主题制作工具（Yata 等），做完导出文件后同样走 Anemone3DS 安装；做机详见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
- **启动画面只在 CFW 引导时显示**：开机经过 Luma3DS 才看得到自定义画面，这是正常现象，不是没装上。
- **BGM 音量跟随系统设置**：嫌主题背景音乐吵，在系统设置的音乐播放选项里调低即可，不用卸主题。

## 推荐流程

1. **获取主题文件**：到 Theme Plaza 等社区站点挑选，预览确认风格和兼容性描述后下载主题包（启动画面、徽章同理，各找对应分类）。这一步在电脑上完成。官网：[Theme Plaza](https://themeplaza.art/)。
2. **安装 Anemone3DS**：这是 3DS 端唯一需要的管理工具，装好后可同时管理主题、启动画面和徽章。安装方式与前置条件见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
3. **安装主题**：把下载好的文件传到 SD 卡，打开 Anemone3DS 安装，装前先预览确认效果。文件放置路径、格式要求与安装操作见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
4. **启用与切换**：装好后即可在系统里启用；多装几套还可以设置轮换，定期自动换肤。启用、切换和轮换的操作见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
5. **（可选）加启动画面和徽章**：想要全套个性化，再在 Anemone3DS 里分别安装启动画面和徽章，徽章动手前先备份现有的。操作与限制见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。
6. **还原默认**：不想用了，在 Anemone3DS 里卸载主题或回系统设置切回官方主题即可，全程不动其他数据。见 [Anemone3DS](../02-工具百科/Anemone3DS.md)。

新手建议按 1→4 先跑通单个主题，确认机器上的主题工作正常后，再叠加启动画面和徽章，出问题容易定位。
