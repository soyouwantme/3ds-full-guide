# 金手指与截屏

在 3DS 上玩游戏时实时修改数值（金手指）、呼出游戏内菜单、游戏内截屏的功能组合，由 NTR CFW 插件系统承载，Luma3DS 的 Rosalina 菜单则自带部分重叠能力，两者按场景分工使用。

## 一句话理解

- **NTR**：跑在 ARM11 侧的自制插件/补丁系统，能注入正在运行的游戏进程，在它内部挂菜单、改内存、截屏、调试。它本身不是固件，需要一个加载器把它送进系统——这个加载器就是 BootNTR Selector。
- **BootNTR Selector**：负责按你的系统固件版本选择并启动对应的 NTR。版本选错或工具与 Luma 版本不匹配会启动失败或崩溃，装之前先看 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md) 的版本要求。
- **金手指（Cheat）**：一类特殊的 NTR 插件，本质是对游戏内存做搜索后写下的补丁，按文本格式存放，进游戏自动加载。

在折腾生态里，NTR 是"游戏运行时增强"的标准方案：LayeredFS 负责启动前替换游戏文件（见 [游戏与汉化](../03-游戏与体验/30-游戏与汉化.md)），NTR 负责游戏跑起来之后的实时干预，两者互补。

## 能干什么

| 场景 | 说明 | 靠什么 |
| --- | --- | --- |
| 改游戏数值 | 无限生命、金币、经验等，勾选即生效 | NTR 金手指（文本码或插件） |
| 游戏内实时菜单 | 不退出游戏呼出菜单、随时开关功能 | NTR 注入的游戏内菜单 |
| 游戏内截屏 | 游戏画面存成图片文件 | NTR 截屏，或 Rosalina 菜单的 Take screenshot |
| 调试用 | 进程查看、内存读写等开发向能力 | NTR 调试功能（折腾汉化/逆向时用得多） |
| 屏幕滤镜等增强 | NTR 注入后附带的一些画面增强选项 | NTR 插件 |

## NTR 与 Rosalina 的分工：什么时候用哪个

Luma3DS 自带的 Rosalina 菜单（开机后随时呼出，见 [Luma3DS](../02-工具百科/Luma3DS.md)）与 NTR 有部分重叠，但不互相替代：

| 需求 | 用哪个 | 原因 |
| --- | --- | --- |
| 只是游戏/系统里截个屏 | Rosalina 菜单 | 免启动 NTR，零准备，PNG 直接存 `/luma/screenshots/` |
| 查屏幕类型、调亮度、看进程、关机重启 | Rosalina 菜单 | 这些是 Rosalina 独有的系统向功能 |
| 玩游戏中改数值、要金手指菜单 | NTR（BootNTR） | Rosalina 的 Cheats/Plugin loader 与 NTR 同时注入同一游戏易冲突，二选一；要完整金手指体验就走 NTR |
| 要对游戏进程做调试 | NTR | Rosalina 的进程列表只提供查看和挂载，调试能力在 NTR |

一句话分工：**只是顺手截屏、查系统信息，用 Luma 自带的 Rosalina 菜单，不必启动 NTR；玩游戏途中要改数值、要实时菜单、要调试，再启动 NTR。** 两条截屏路线得到的都是 PNG 文件，Rosalina 的截屏固定存 `/luma/screenshots/`，转存电脑见 [43-文件传输.md](43-文件传输.md)。

## 原理：金手指是怎么改到游戏数值的

游戏运行时的血量、金币等数据都存在内存里。金手指的通用做法分两步：

1. **搜索定位**：在游戏中让数值变化（比如花掉 100 金币），对内存做差值搜索，几次筛选后锁定存放这个数值的内存地址。
2. **打补丁**：把"该地址恒等于某值"或一段修改代码写成补丁文件，由插件系统在游戏运行时持续生效。

NTR 的文本码就是这类补丁的标准文本格式：以游戏 TitleID 命名的 `.txt` 放在 SD 卡 `/cheats/` 下，内容是 `[码名]` 加若干代码行，进游戏后 NTR 自动加载，呼出菜单勾选生效；功能更复杂的（带界面、多选项的）做成 `.3gx` / `.plg` 插件文件放 `/plugin/`。具体路径与格式见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。

因为是直接改运行中的内存，**代码与游戏版本、系统固件版本强相关**：游戏更新或固件升级后，旧地址可能指向别处，轻则无效，重则死机。来源不明、未注明适用版本的码慎用。

一个文本码文件大致长这样（仅示意格式，不是可用代码）：

```
[金币无限]
D3000000 00000000
B0000000 00000000
```

方括号里是菜单里显示的码名，下面是机器执行的代码行；一个文件可以写多组码，进游戏后逐条勾选。写码、转码的工具和获取途径本文不展开，见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。

## 注意事项

- ⚠️ **工具版本要匹配系统**：BootNTR Selector 对 Luma3DS 版本有硬性要求（当前最新版要求 Luma v13.0 或更新），各 NTR 模式（3.2 / 3.6 等按固件选择）的区别与 Mode3 的用法只在工具文档里说明，装之前读 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。
- ⚠️ **一次只能进一款游戏**：NTR 注入后一次只能进一款游戏；想换游戏要先关机重启，连续切换会死机。
- ⚠️ **与 Luma 自带插件加载二选一**：新版 Luma（v13+）自带 Plugin Loader，若与 NTR 同时往同一游戏注入插件容易崩溃，选一个用即可。
- ⚠️ **老三的大内存游戏要用 Mode3 版**：旧 3DS/2DS 上以扩展内存模式运行的游戏（判断线索：从 HOME 菜单关闭游戏时主机会重启）必须用 Mode3 版 BootNTR 才能注入；新三不需要。详见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md) 的 Mode3 说明。
- ⚠️ **固件升级后金手指可能失效**：代码分系统版本，升级系统固件后先确认手里的码仍适用，再进游戏勾选。
- ⚠️ **联网游戏用金手指的风险**：官方在线服务已关停，如今的联机多依赖 Pretendo 等社区服务，其反作弊与封禁规则由社区运营方决定；在社区服务器上使用修改过的数据（异常数值、改出来的道具）有被封禁账号的风险，也可能影响其他玩家。联机背景与 Pretendo 介绍见 [46-联网对战.md](46-联网对战.md)。单机自用则无此顾虑。

## 推荐流程

1. 在破解完成的机器上安装 BootNTR Selector（3dsx 或 CIA 版任选），注意核对它与当前 Luma3DS 的版本要求。详见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。
2. 按游戏 TitleID 准备好金手指文本码或插件，放到 SD 卡对应路径（`/cheats/`、`/plugin/`），放好即生效，无需安装。格式与路径见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。
3. 开机进 HOME 菜单后启动 BootNTR Selector，按系统固件版本选择对应的 NTR，屏幕闪烁表示注入成功。启动方法见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。
4. 回到 HOME 菜单再进游戏，游戏内呼出 NTR 菜单，勾选要用的金手指代码或插件。呼出方式与菜单操作见 [BootNTR与金手指](../02-工具百科/BootNTR与金手指.md)。
5. 需要截屏但不想动用金手指时，直接用 Rosalina 菜单的截屏即可，截屏文件在 `/luma/screenshots/`。见 [Luma3DS](../02-工具百科/Luma3DS.md)。
6. 玩完想换游戏：关机重启，重新从第 3 步开始（一次只能进一款游戏）。
