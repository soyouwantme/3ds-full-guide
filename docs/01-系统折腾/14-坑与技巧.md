# 3DS 坑与技巧

遇到坑时先查这里；新坑按 `## 标题` 追加。

## Luma 过旧导致开机黑屏（电源灯亮）

- 现象：开机黑屏、电源灯常亮，但 START 能进引导选单。
- 原因：SD 卡 `boot.firm` 是多年前的旧版 Luma（如 v7.x），不支持较新固件。二手卖家的卡不要默认能用，先 `strings boot.firm | grep Luma` 或在 SELECT 菜单确认版本。
- 解决：换最新 `boot.firm`（`tools/3ds/Luma3DS-v13.4/`）。替换前把旧文件改名备份（如 `boot_v7.1_old.firm.bak`）。

## Luma v13 按住 START 开机是配置菜单

- 不是以前的 chainloader 直接选 payload，而是先进 Luma 配置界面，chainloader 入口是菜单里的 **Boot chainloader**。
- 配置改动必须选 **Save and exit** 才写入；只选 Boot chainloader 直接走，改动不保存。

## GodMode9 脚本 `cp` 文件夹的坑

- `cp <目录> <目标>`：目标**不能已存在**，否则报“用目录覆盖文件”；想合并必须界面手动 Paste 或先删目标。
- 脚本某行报错后按 A“继续”**会继续执行后续行**（不是终止），配合 `rm` + `cp -s`（静默跳过错误）可能制造出“删了旧的、新的没拷进去”的半成品状态。
- 结论：NAND 写操作别用自写脚本，用官方安装器或界面手动操作。

## title.db 与 import.db 是配对的

- 只把别台机器的 `title.db` 拷进 NAND 而保留自己的 `import.db`，重启即 ARM9 崩溃（prefetch abort / svcBreak）。
- 系统数据库要整套一致；跨机器搬系统文件这条路不可靠，建议弃用。

## 装软件报 missing .db files / 开机黑屏 / 0xD900458A

- 一律先查 [15-软件数据库与黑屏救援实录.md](15-软件数据库与黑屏救援实录.md)：db 错误先看 SD 侧、0 字节文件不进 NAND、NAND 库不能拷到 SD（加密不同）、无 FBI 用 Rosalina 切 hb 走 FBI.3dsx。

## GM9Megascript “SysNAND Restore (safe)” 只会扫 gm9/out/

- 备份必须是 `gm9/out/*nand_??.bin` 的位置和命名，放 SD 根目录会报 “no usable entries found”。
- 实测 v2.2.3 不会删除源备份（早期记录“会自动删除”有误，以源码为准）。还原后 movable.sed 回到备份时版本 → ID0 变化，详见 [15-软件数据库与黑屏救援实录.md](15-软件数据库与黑屏救援实录.md)。

## 洁癖版补丁在“被改写的 HOME 菜单”上静默失效

- 早年改机店装的“简体中文系统”机（SD 卡上常有 SharedFontTool 教程、ACG 字库等遗留），NAND 里 HOME 菜单被注入过非原版。
- LayeredFS 补丁（code.ips 按固件版本针对原版代码）完全静默不生效，系统照常日文启动，无报错。
- 判断线索：补丁在同版本机器上能用、某台机器就是不行 + 机器来源是改机店。解法：F君 官方安装器完整版（自动换 HOME 菜单 CIA），流程见 [11-简体中文系统.md](11-简体中文系统.md)。

## F君 官方安装器流程（成功路径）

- 补丁包：发布者网盘 `pan.wdtngzs.top`（OpenList，POST `/api/fs/list` 列目录、`/api/fs/get` 拿 raw_url 可 HTTP 直链下载，不走 torrent）。Build 0905J 日志写明支持到 11.16，**11.17.0-50J 实测可用**。
- 流程：`luma/payloads/Chinese_System_Installer.firm` + `gm9/scripts/Chinese_System_Installer.gm9` + SD 根目录 `apps/` → START 开机选 Chinese_System_Installer → Install SC → SysNAND → 按键确认 → Clear HOME Menu Caches (SYSNAND) → 重启。
- 全程约 5-10 分钟，装完 `apps/`（365MB）可经安装器 Delete Apps 删除。

## macOS 访达 FTP 只读

- 现象：访达连接 ftpd 后无法上传、删除、重命名。
- 原因：macOS 访达的 FTP 连接是只读的，只能浏览和下载。
- 解决：用 FileZilla 或命令行（curl）操作；命令见 [ftpd与文件传输.md](../02-工具百科/ftpd与文件传输.md)。

## ftpd 删除是永久删除

- FTP 删除不经过回收站，`curl --quote "DELE /路径" ftp://192.168.1.78:5000/` 会直接删除。

## Anemone3DS 不认解压后的主题文件夹

- Anemone3DS 只扫描 `/Themes` 下的 `.zip` / `.s3dz`，压缩包内文件必须在根目录（`body_LZ.bin` 等）。
- 解压后的散目录不会显示；打包方法见 [Anemone3DS.md](../02-工具百科/Anemone3DS.md)。

## TWiLight 默认不显示 GBA 游戏

- 现象：`roms/gba/` 里有 `.gba`，但 TWiLight 列表里不显示。
- 原因：GBA 需要安装 Virtual Console 扩展包，`GBARunner2` 也随扩展包提供。
- 解决：安装 `AddOn-VirtualConsoleFull-3DS.7z`；详见 [../04-功能模块/45-NDS与GBA.md](../04-功能模块/45-NDS与GBA.md)。

## NTR 金手指一次只能进一款游戏

- 启动金手指（NTR/BootNTR）后，一次只能进入一款游戏；想换游戏要先关机重启，连续切换会死机。
- 游戏内按 **Y+X** 呼出金手指菜单。

## SD 卡建议 FAT32 + 32KB 簇

- 64GB 卡使用 FAT32 主分区、簇大小 32KB；格式化细节见 [10-备份与恢复.md](10-备份与恢复.md)。

## NAND 备份时间戳异常

- 3DS 时钟未校时时，备份文件的修改时间会显示为 2001 年，无法据此判断真实备份日期。建议定期重做的同时，把真实备份日期另行记录在备份清单里。

## 敏感文件不要上传

- `movable.sed`、`boot9.bin`、`essential.exefs`、NAND 备份可用于解密机器数据，不要上传网盘/GitHub/聊天群；建议单独加密备份。

## macOS 产生的 `._*` 文件可忽略

- macOS 在 FAT32 卡上会产生 `._文件名` 元数据文件，不影响 3DS，可忽略或清理。

## `arm9loaderhax.bin` 是旧式引导遗留

- 不影响 boot9strap 启动，可留可删。
