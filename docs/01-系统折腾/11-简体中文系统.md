# New 3DS 日版 → 简体中文系统 操作清单

适用：日版 New 3DS / New 3DS XL，boot9strap + Luma3DS ≥ v10.3（建议 v13.x），系统固件 11.15~11.17。

## 标准流程

前置条件：日版机、B9S + Luma ≥ 10.3、系统固件、**改机前已做过 NAND 备份**。

1. **更新 Luma 到 v13.x**：替换 SD 卡根目录 `boot.firm`（`tools/3ds/Luma3DS-v13.4/` 有留档）
2. **确认 game patching 开启**：SELECT+开机 → `Enable game patching` 打 `(x)` → Save and exit
3. **把补丁包装入 SD 卡**：
   - `luma/payloads/Chinese_System_Installer.firm`
   - `gm9/scripts/Chinese_System_Installer.gm9`
   - `apps/`（365MB，安装数据包，装完可删）
4. 关机 → 按住 **START** 开机 → 选单选 `Chinese_System_Installer`
5. 主菜单 → **Install SC**（简体）→ **SysNAND** → 按提示输入按键组合
6. 约 2 分钟装完 → **Other Functions** → **Clear HOME Menu Caches** → **SYSNAND**
7. 退出重启 → 简体中文系统

补丁包来源：F君 发布（参考来源见下文；OpenList 网盘可 HTTP 直链下载，见 `tools/3ds/chs-patch-official/`）。Build 0905J 标称支持到 11.16，**11.17.0-50J 实机验证可用**；2026-10-11 本机已更新至 Build 0953J Hotfix1（数据包由 `apps/` 文件夹改为 `os_chn.pak` 封装，见 `local/New3DS-YJM10107872/chs-update-0953J/`）。

## 验收要点

装完后逐项确认：

- [ ] HOME 菜单、本体設定显示简体中文
- [ ] 日文游戏文字正常
- [ ] Mii 广场、相机等系统应用正常

## 出问题怎么办（还原方法）

1. 关机 → 按住 **START** 开机（Luma v13 先显示配置菜单时，选 **Boot chainloader** → `GodMode9.firm`）
2. **HOME** → `Scripts...` → `GM9Megascript` → `Restore Options` → `SysNAND Restore (safe)`
3. 选择备份的 `.bin`，按提示解锁写入，等待完成（约 20-40 分钟，**保持充电**）

> ⚠️ `Restore (safe)` 还原成功后会**删除 SD 卡上的备份 .bin**（属正常现象）。如需保留 SD 卡副本，还原前先手动复制走。补丁类问题也可先尝试卸载：START 进 `Chinese_System_Installer` → Uninstall SC&TC。

## 注意事项

- 升级系统大版本前，先看 F君 补丁日志是否支持新版本（`local/New3DS-YJM10107872/chs-update-0953J/` 及各机器 `chs-install-official/` 留档里的`日志 日版.html`）
- 官方安装器会自动在主机 NAND 里做一份备份；电脑上另存的整盘备份是最终兜底
- 如果 Luma 只装在 SD 卡，不插卡会无法开机；可以把 Luma 装进 CTRNAND（见 [../00-新手上路/02-破解后初始化.md](../00-新手上路/02-破解后初始化.md)）
- 早年改机店的"简体中文系统"机，NAND 里的 HOME 菜单可能不是原版，LayeredFS 类洁癖补丁会静默失效；这种情况直接用官方安装器（它会自动替换 HOME 菜单），详见 [14-坑与技巧.md](14-坑与技巧.md)
