# 备份与恢复

本篇聚焦备份与恢复：SD 卡备份/格式化、二手到手清理、敏感文件。破解流程见 [../00-新手上路/01-破解流程.md](../00-新手上路/01-破解流程.md)，破解后的初始化检查单见 [../00-新手上路/02-破解后初始化.md](../00-新手上路/02-破解后初始化.md)，各工具详细用法见 [../02-工具百科/README.md](../02-工具百科/README.md)。

## 二手到手清理步骤

系统初始化（本体設定 > その他設定 > 初期化）只会清除系统内存里的用户数据，不会删除 SD 卡内容，也不会卸载 boot9strap 和 Luma3DS。上一任使用者的大部分痕迹其实在 SD 卡上，所以两步都要做：

1. 先完整备份 SD 卡到电脑（含隐藏文件；文件多的话做逐文件内容校验，确认数量一致、无差异）
2. 开机确认系统里是否还登录着卖家的 NNID；联网状态下初始化会移除当前 NNID，之后可以创建或绑定新账号
3. 在系统设置里选择“本体初期化”，不要选“本体 + SD 卡初期化”
4. 格式化完成后，把 SD 卡插到电脑，重新格式化为 FAT32（簇大小 32KB），旧存档、Nintendo 3DS、DCIM、主题等全部清掉
5. 从备份里只拷回 CFW 必需文件：`boot.firm`（必需）、`boot.3dsx`（可选）、`luma/`（可选）、`gm9/`（可选）
6. 不要拷回 `movable.sed`、`boot9.bin`、`Nintendo 3DS/`、`JKSV/`、`DCIM/` 等上一任用户的私人数据
7. 开机后系统会生成新的 ID0，机器变成全新状态，再重新安装需要的自制程序和游戏

### NNID 相关的注意事项

- 任天堂官方说明：联网状态下格式化系统，会移除当前绑定的 NNID，之后可以创建或绑定新的 NNID；被移除的账号之后还可以重新绑定回原机器。
- 如果离线格式化，旧 NNID 可能在任天堂服务器端残留绑定，之后想绑自己的账号可能报错，需要联系任天堂处理。3DS 在线服务已经关停，这条现在更难操作。
- 官方同时说明：格式化不会把 NNID 转移到另一台机器（那是 System Transfer 的功能），这主要影响卖家，不影响新机主。
- 3DS 的 eShop 和官方联机服务已经关停，NNID 对日常使用影响已经很小，不必为了保留它而放弃清理。

来源：[Nintendo Support - How to Format](https://en-americas-support.nintendo.com/app/answers/detail/a_id/258)、[Nintendo Support - Wrong NNID](https://en-americas-support.nintendo.com/app/answers/detail/a_id/2231)

### 初始化会丢失什么

根据任天堂官方说明，格式化系统内存会丢失：

- 系统内存里的所有数据：好友列表、通知、计步、活动记录等
- 系统设置数据（个人设置、主题布局、家长控制等）
- 内置软件和应用的存档
- 系统更新数据
- 所有下载软件及其存档、DLC、额外数据、存档备份（SD 卡上的这些数据会失效）
- 系统内存里保存的照片
- 当前绑定的 NNID 链接，以及关联的 eShop 授权和余额

不会丢失：

- 系统版本（格式化不会降级或改变系统固件）
- boot9strap 和 Luma3DS（自制固件不会被卸载）
- 实体卡带里的游戏存档（3DS 卡带存档存在卡带上）
- SD 卡里你自己拍摄的照片和视频（DCIM 目录）
- NNID 账号本身（只是解除了与原机器的绑定）

来源：[Nintendo Support - What is Lost after Formatting](https://en-americas-support.nintendo.com/app/answers/detail/a_id/166)

## 敏感文件提醒

破解后的 SD 卡根目录通常有 `movable.sed` 和 `boot9.bin`（GodMode9 的 `essential.exefs` 备份也包含同类密钥），这两类文件可以用于解密机器的系统数据，非常敏感：

- 不要上传到网盘、GitHub、聊天群等任何地方
- 不要发给任何人或商家
- 建议单独备份到电脑的加密目录，并把 SD 卡根目录的副本收进安全文件夹

另外 `/3ds/3hs/` 属于第三方商店客户端，本篇不整理使用说明；游戏安装请只使用你合法拥有的来源。

## SD 卡常见目录

| 路径 | 作用 |
| --- | --- |
| `/boot.firm` | Luma3DS 引导文件，不要随意删除 |
| `/luma/` | Luma 配置、区域模拟等设置 |
| `/3ds/` | 各类 `.3dsx` 自制程序 |
| `/cias/` | 存放待安装的 `.cia` 文件 |
| `/gm9/` | GodMode9 脚本和备份输出 |
| `/gm9/out/` | NAND 备份等关键文件的输出位置 |

## 安全提醒

- 只安装自己合法拥有或来源可靠的自制程序；本文档不整理盗版下载指引。
- 改机后系统更新通常可以正常进行，但前提是 Luma3DS 保持较新版本。
- 不要删 SD 卡根目录的 `boot.firm`，删了开机会无法进入自制系统。
- 任何重要操作前先做 NAND 备份和存档备份。
- 遇到问题时优先查 [3ds.hacks.guide](https://3ds.hacks.guide/)，不要照搬旧教程。
