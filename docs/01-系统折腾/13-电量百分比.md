# 电量百分比显示（HOME 菜单顶栏）

给 HOME 菜单顶栏加电量百分比显示。参考视频：《【3DS】3DS电量百分比显示插件 完善版》（<https://b23.tv/HVWNqu5>），配套补丁文件在本仓库 `tools/3ds/battery_percentage/`。

## 原理：HOME 菜单 LayeredFS 补丁

3DS 顶栏电量只有图标、没有百分比。这属于系统 UI 功能，要改的是 **HOME 菜单本体**（系统标题，存 NAND），破解机通过 **Luma3DS 的 LayeredFS** 对它打补丁：

- 补丁放在 SD 卡 `luma/titles/<HOME菜单TID>/`，Luma 加载 HOME 菜单进程时用补丁文件替换/修改原资源，**不改 NAND 里的原文件**，删掉目录即还原。
- 日版 HOME 菜单的 TID 是 **`0004003000008202`**（与 `GM9Megascript.gm9` 里的官方区域表一致；FBI → 标题列表里「ホームメニュー」可再核对）。
- 补丁由三类文件组成：

| 文件 | 作用 |
| --- | --- |
| `code.ips` | 改 HOME 菜单代码（在顶栏绘制逻辑里插入百分比） |
| `exheader.bin` | 覆盖 exheader，给代码段扩容（补丁代码超过原空间时需要） |
| `romfs/…` | 替换 HUD 资源：`hud_LZ.bin`（HUD 布局）、`font/Hud_JP.bcfnt`（HUD 日文字体） |

## 版本匹配（最重要）

HOME 菜单代码随**系统固件版本**变化，`code.ips` 是针对特定固件的日版 HOME 菜单做的。补丁目录按版本分：

- 例如系统 **11.17.0-50J** → 用 `tools/3ds/battery_percentage/11.17.0-50J/` 下的文件。
- **版本错配**的后果：补丁不生效，或 HOME 菜单起不来（黑屏/报错）。装之前先确认系统版本（本体設定右上角 `Ver. xx.x.x-xxJ`），升过级就要用新版本对应的补丁目录。

前置条件：Luma3DS + **Enable game patching**（长按 Select 开机在 Luma 配置页勾选）。

## 三种样式变体

`11.17.0-50J/` 下有三个互斥的变体，效果只差顶栏显示方式：

| 变体 | `code.ips` 大小 | `romfs/` 资源 | 效果 |
| --- | --- | --- | --- |
| `both` | 632 B | 有 | 电量图标 + 百分比数字同显 |
| `statusbatpercent` | 506 B | 有 | 只显示百分比数字 |
| `statusbaticon` | 370 B | 无 | 只改图标相关代码（无资源替换，效果未实测） |

> `statusbaticon` 的效果说明材料里没有，仅凭文件结构推断；想用的话装完看一眼效果，不满意再换回。

切换变体 = 换掉 SD 卡 `luma/titles/0004003000008202/` 里的内容，互不影响。

## 文件位置与校验

- 补丁原件：`tools/3ds/battery_percentage/11.17.0-50J/{both,statusbatpercent,statusbaticon}/luma/…`
- 拔卡直拷成品：`tools/3ds/battery_percentage/SD-COPY/luma/…`（即 both 变体，README.txt 含安装/还原说明，附 `SHA256SUMS.txt` 可核对）
- 推送脚本：`tools/3ds/battery_percentage/push-battery-patch.py`（inspect / push / clean 三个子命令，上传后回读逐字节校验）

## 安装

### 方式 A：无线（ftpd）

1. 3DS 开 ftpd（和电脑同一 Wi-Fi），记下屏幕 IP（默认端口 5000）。
2. 电脑上先看目标目录现状：

   ```bash
   python3 tools/3ds/battery_percentage/push-battery-patch.py inspect --host <3DS的IP>
   ```

3. 推送并校验（只新增/覆盖 `luma/titles/0004003000008202/`，不删 SD 上其它文件）：

   ```bash
   python3 tools/3ds/battery_percentage/push-battery-patch.py push --host <3DS的IP> --yes
   # 换其它样式: --variant statusbatpercent / statusbaticon
   ```

4. 退出 ftpd（HOME 键返回，让写入落盘），重启进 HOME 菜单验证。

### 方式 B：拔卡直拷

把 `tools/3ds/battery_percentage/SD-COPY/luma` 的内容拷到 SD 卡根目录（与已有 `luma/` 合并）即可，必要时用 `SHA256SUMS.txt` 核对。

## 验证与排查

- 效果：HOME 菜单顶栏电量图标旁显示百分比数字。
- 没变化：长按 Select 开机确认 `game patching` 勾选 → 重启再看；仍无效去 FBI → 标题列表核对「ホームメニュー」TID 是否为 `0004003000008202`（名称是日文系统里显示为 ホームメニュー）。

## 还原 / 崩溃恢复

- **还原**：删除 SD 卡 `luma/titles/0004003000008202/` 整个目录（ftpd 里删、拔卡删、或脚本 `clean` 都行）。
- **崩溃兜底**：万一 HOME 菜单起不来（黑屏/报错），长按 **Start** 开机仍可进 GodMode9——补丁只影响 HOME 菜单进程，不影响 Luma/boot9strap 引导；在 GM9 里删掉上述目录再重启即恢复。

## ftpd 来源

部分机器 SD 卡没装 ftpd。官方发布在 [mtheall/ftpd Releases](https://github.com/mtheall/ftpd/releases)（v3.2.1 实测），下载 `ftpd.3dsx` 放 `3ds/ftpd/ftpd.3dsx`（Homebrew Launcher 启动），`ftpd.cia` 放卡里用 FBI/GM9 安装。直连 github 下载中断时可用 `gh release download --repo mtheall/ftpd --pattern 'ftpd.*'`。

## 踩坑

- **ftpd 430 Invalid user**：ftpd-3ds 是单客户端服务，上一次连接没正常释放时，新连接会被拒（`430`，连匿名也一样）。处理：重启一次 ftpd。若 ftpd 设置了账号密码，用 `--user / --passwd` 传。
- **版本/区域错配**：补丁目录名（固件版本）和 TID（区域）都必须与机器匹配，否则静默不生效或开机崩。TID 可通过 GM9Megascript 区域表或 FBI 标题列表核对。
